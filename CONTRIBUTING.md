# Contributing to DataForge Toolkit

Thank you for your interest in contributing! We welcome bug reports, feature
requests, documentation improvements, and pull requests.

## Code of Conduct

This project is governed by our [Code of Conduct](CODE_OF_CONDUCT.md). By
participating, you agree to uphold it.

## Getting Started

1. Fork the repository.
2. Clone your fork:

   ```bash
   git clone https://github.com/mwakidenis/DataForge-Toolkit.git
   cd DataForge-Toolkit
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Making Changes

1. Create a feature branch:

   ```bash
   git checkout -b feat/your-feature-name
   ```

2. Implement your changes following the existing code style.

3. Typecheck and lint:

   ```bash
   npm run typecheck
   npm run lint
   ```

4. Build:

   ```bash
   npm run build
   ```

5. Commit using [Conventional Commits](https://www.conventionalcommits.org/):

   ```
   feat: add your feature
   fix: resolve an issue
   docs: update documentation
   chore: maintain tooling
   ci: update CI workflows
   ```

6. Push and open a pull request:

   ```bash
   git push origin feat/your-feature-name
   ```

## Pull Request Guidelines

- Keep PRs focused on a single concern.
- Include a clear description of what changed and why.
- Reference any related issues.
- Ensure all checks pass before requesting review.
